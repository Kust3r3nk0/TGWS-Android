# Проверка 0.3.1-alpha

16 октября 2026 UTC. [English](en/TEST_REPORT_0.3.1-alpha.md).
Android 15+, minSdk 35, versionCode 7.
**Проверка владельцем на физическом устройстве: ожидается.**

## Изменения

Две Material 3 вкладки, отдельные настройки MTProxy и сохранение без запуска;
постоянные светлая/тёмная/системная темы и кнопка в меню. На главной — текущая сеть
и IPv4/IPv6/dual-stack независимо от запуска прокси. Link-local не считается
поддержкой интернет-семейства. DNS — системный по умолчанию или выбранный пользователем
Cloudflare DoH со строгим TLS/A/AAAA, ограничением данных и отменой.
[Поведение и ограничения](DNS_AND_APPEARANCE.md).

## Автоматические проверки

Целевые тесты DoH проверяют настоящий локальный TLS/H2, A/AAAA, отсутствие системного
bootstrap/fallback, NXDOMAIN, повреждённый DNS, HTML, размер ответа, redirect,
недоверенный сертификат, stop и запоздалый ответ прежней сети. Выявленный при тестировании
зависавший DNS wait исправлен явной отменой Dns.Call и завершением ожидающего future.
В старом тесте повреждённого MTProto-пакета исправлена гонка проверки: локальный EOF
мог прийти раньше finally-close удалённого канала; освобождение теперь проверяется
с конечным deadline, без отключения проверки или изменения протокола.

Полная локальная Wrapper-команда: **BUILD SUCCESSFUL**, 181 JVM case, 0 failures/errors/skipped;
Lint — 0 errors / 3 прежних UseKtx warnings, Debug APK и instrumentation APK собраны.
Фактические CI JUnit будут зафиксированы после выполнения матрицы.
Прежние 176 тестов сохранены, новых JVM — 5 (итого 181). В исходниках 22 Android cases,
включая новые навигацию/сохранение/тему и настоящий локальный DoH на Android.
Android CI собирает снимки главной в двух темах и настроек; они требуют визуальной проверки.
Матрица API 35/36/37 не считается PASS до проверки всех реальных JUnit.

## Ограничения

Физический телефон, публичный Cloudflare DNS через конкретного оператора, мобильный
интернет и Telegram новой версии — NOT TESTED. Локальный DoH-сервер доказывает поведение
клиента, а не доступность 1.1.1.1 у оператора. DNS Android/APN/SIM не изменяются;
Cloudflare DoH не гарантирует обход IP-блокировки и не заменяет операторский DNS64.
Прежний экспериментальный Worker сохраняет лимит 16 MiB/сессию. Debug APK не имеет
production-подписи; используется прежний debug-сертификат для обновления.
