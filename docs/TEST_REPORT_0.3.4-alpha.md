# Проверки 0.3.4-alpha — 16 октября 2026

Android 15+, versionCode 10. Отчёт заполняется по фактическим результатам CI перед публикацией.

Удалён встроенный Cloudflare DNS, остальные настройки/транспорты сохранены. Семейства TCP
чередуются с шагом 250 мс, двумя попытками и общим deadline. Добавлены регрессии зависшего
IPv6/IPv4, чередования до cap, отказов, отмены/смены сети и миграции; DNS/TCP/TLS/deadline
различаются. Исторические DoH-тесты сохранены вне APK, production DEX проверяется CI.

Физические Android/One UI/WebView Stable/Beta/мобильные сети/Wi-Fi/Telegram: ожидаются от владельца.
Владелец сообщил об отказах прежней сборки во всех трёх режимах; точная версия/SHA и этап
ошибки не указаны. Исправление ограничения у оператора новой сборкой не подтверждено.
