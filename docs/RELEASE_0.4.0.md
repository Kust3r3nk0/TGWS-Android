# 0.4.0 — подготовка стабильного выпуска

Статус: **кандидат**, не опубликованный Stable. Исходная база — объединённый PR #19 / 0.3.10-alpha, SDK 36+/37.0, versionCode 17. Сетевое ядро сохраняется.

## Архитектура интерфейса

`MainActivity` связывает существующий сервис с навигацией. `ProxyFormModel` хранит чувствительный черновик только в ViewModel и выполняет сохранение через прежний SettingsStore/Keystore. `AppScaffold` сохраняет состояние прокрутки отдельно для страниц. `DashboardScreens` отображает существующие счётчики и нативные Material 3 элементы; `SettingsScreens` организует все прежние параметры по подразделам. `UpdateCenterUI` использует общую палитру, Repository/Worker/Downloads/Installer не переписаны.

`DiagnosticHistory` принимает только типизированные события и числа, не строки исключений/адресов. Пределы — 128 событий, 32 установки транспорта, только память процесса. Успешный setup не равен Telegram E2E или ping; график подписан соответствующим образом. Таймер uptime использует monotonic clock, останавливается при закрытии вкладки/Activity. Пробы остаются ручными. Отключение журнала очищает события/замеры, не отключая счётчики и проверки ядра.

## Подпись и миграция

Для PR CI: `./gradlew --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest :app:lintRelease :app:assembleRelease`.
Без ключа `assembleRelease` создаёт **app-release-unsigned.apk**, непригодный для распространения. CI дополнительно проверяет minSdk/applicationId/version/debuggable/размер; unsigned-файл не публикуется как установочный Release.

Для доверенной подписи настройте **отдельный Release-keystore**, надёжно сохраните резервную копию вне Git. В GitHub environment `production-signing` включите обязательное одобрение владельца и добавьте Secrets:

- `TGWS_RELEASE_KEYSTORE_BASE64` — содержимое keystore, Base64.
- `TGWS_RELEASE_STORE_PASSWORD`, `TGWS_RELEASE_KEY_ALIAS`, `TGWS_RELEASE_KEY_PASSWORD`.
- `TGWS_RELEASE_CERT_SHA256` — заранее проверенный SHA-256 сертификата, 64 HEX без двоеточий.

Не присылайте ключи/пароли в чат. Локальная сборка использует `TGWS_RELEASE_STORE_FILE` вместо Base64; остальные переменные те же. Не печатайте переменные в терминале/логах.

Workflow **Signed production candidate (no publication)** выполняет Release unit/Lint/build, apksigner integrity/certificate verification, проверяет запрет Debug-сертификата, отсутствие debuggable и бюджет APK 80 MiB. Он сохраняет APK, manifest Stable, RU/EN changelog/notes, source commit, verification и SHA256SUMS только как Actions artifact. Workflow не создаёт тег/Release и не объединяет PR.

Ранее опубликованные Debug APK подписаны иным ключом. Android отвергнет установку нового Release поверх них (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`); Keystore связан с установленным приложением. Нельзя обещать сохранение секрета при удалении/смене подписи. Автоматическое удаление запрещено. Пользователь может **явно** сохранить Telegram-ссылку/секрет и вручную повторно ввести настройки в новой установке, понимая потерю старых Keystore-данных. Публичные отчёты не содержат конфигурацию. Инструментальный `install -r` 0.3.10→0.4.0 проверяет только сохранение с **одинаковой временной CI-подписью**, а не миграцию Debug→Release.

## Проверка владельцем

Устанавливать тестовый APK поверх прежней Debug-сборки можно только при совпадении сертификата; не удалять прежнюю установку ради обхода ошибки. Проверить три вкладки, сохранение черновика и прокрутки, темы/крупный шрифт/эффекты, start/stop/фон, домашний Wi-Fi/мобильный интернет и смену сетей. Проверить Telegram, SD/HD фото, видеосообщения, большие передачи в обе стороны и восстановление после разрыва. Проверить ручное/фоновое обновление и разрешения. Результаты сообщать в чате без секретов, адресов и личных сведений.

Stable gate: успешные автоматические проверки API 36/37; реальные скриншоты; доверенно подписанный Release APK и совместимость будущих обновлений; физическое подтверждение владельца, включая HD-медиа; отдельное одобрение публикации. Только после этого тег `v0.4.0` и обычный GitHub Release.
