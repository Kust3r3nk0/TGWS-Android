# Диагностика 0.4.1

Откройте вкладку **Диагностика**. Основные счётчики показывают состояние локальной службы и транспортов; открытый порт не подтверждает Telegram.

## Как разобрать сбой без компьютера

1. Включите запись в **Настройки → Диагностика**.
2. Повторите проблему, затем откройте **Диагностика → Весь журнал**.
3. Выберите уровень и категорию. Раскройте подробный журнал: он содержит DC/media, этап, попытки, измеренные времена и безопасную причину закрытия.
4. Нажмите **Предпросмотр отчёта**, просмотрите JSON и выберите копирование или **Поделиться отчётом JSON**. Отправка всегда явная через системное меню.

INFO — обычное событие; WARNING — отказ отдельного клиента/маршрута или неподтверждённая сеть; ERROR — ошибка локальной службы/конфигурации/хранения. Уровень события не меняет состояние работающих соседних сессий. Повторные предупреждения объединяются; указаны количество и время первого/последнего события в JSON. В logcat тег `TGWSDiagnostics` выводит только типизированные безопасные поля, с ограничением повторов.

История хранит до 128 событий и 32 реальных измерений в памяти. Отключение записи очищает их и прекращает журналирование; состояние службы и счётчики продолжают работать. Завершение процесса также очищает историю. Уже экспортированные копии не удаляются из внешнего приложения получателя.

## Инструменты

**Проверить локальный порт** — одно TCP-подключение к выбранному порту `127.0.0.1`, без отправки секрета. Запрос ограничен 1,5 секунды и отменяется с закрытием сокета. Отказ может означать остановленную службу или неверный порт. Успех не подтверждает MTProto secret, удалённый транспорт или задержку Telegram. Изменение порта сбрасывает прежний результат.

**Проверка маршрутов** — существующая явная проверка настроенных удалённых транспортов. Транспортные setup-замеры и их DNS/TCP/TLS/HTTP части показываются только при наличии данных. Подсказки основаны на наблюдениях; тайм-аут не доказывает причину операторской блокировки.

**Системный WebView** — выбранный провайдер, точная установленная версия и предполагаемый канал по package name. Сведения обновляются при возврате в приложение, изменении выбранного пакета и по кнопке. Движок и страницы не создаются; логи чужих приложений недоступны. Для свежих Stable/Beta отображается фактическая версия, без заявления о сертификации latest.

## Безопасный отчёт

JSON schema 2 содержит версию TGWS/API, состояние службы/сети, счётчики, маршруты, журнал и метаданные WebView. Он исключает MTProto secret, ключи, relay URL, IP/DNS-адреса, имя Private DNS, оператора и содержимое сообщений. Raw exception messages и stack traces не экспортируются.

Отчёты ограничены 256 КиБ и четырьмя временными cache-файлами. Отдельный неэкспортируемый `DiagnosticFileProvider` выдаёт только явный read-only URI; каталог отчётов не входит в FileProvider установщика APK. Android или следующий экспорт удаляет старые cache-файлы. Настройки и Keystore не изменяются.
