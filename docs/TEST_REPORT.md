проверяет commit, чистоту `proxy/` и записывает SHA-256 исходных файлов.

Проверяются `ef`/`ee`/`dd`, DC 1–5 и сохранённый DC 203, media DC,

строже upstream по требованиям ТЗ. [Воспроизведение](../tools/README.md).

### Достоверность Android-проверок

Предыдущие артефакты API 34, 35 и 36 содержат по **10 прошедших тестов**.
«Успешный» прогон API 37 не содержал ни одного JUnit-теста: эмулятор
перезапускал системные службы, а Gradle завершился без ошибки после отказа
установки APK. Этот результат **не засчитывается**.

Теперь workflow проверяет фактический `ro.build.version.sdk` и требует
JUnit-записи каждого инструментального теста без ошибок и пропусков.
Пустой, неполный или повторяющийся отчёт блокирует CI. Для minor-versioned
API 37.0 исправляются метаданные AVD, только если они расходятся с проверенным
путём установленного system image; используется поддерживаемый `-gpu software`.
Скрипты запускаются едиными процессами, поскольку emulator action выполняет
отдельные строки в отдельных оболочках. Приложение и критерии тестов этим
исправлением не изменены.

## Ограничения альфы

- Только loopback `127.0.0.1`, default port `1443`; максимум **8** принятых
  клиентов, включая ожидающие handshake.
- MTProto payload до **4 МиБ**, WS message до **4 МиБ + 4 байта**.
  Буфер ciphertext хранит один пакет; данные пользователя не журналируются.
- Handshake **10 с**, вся установка транспорта **25 с**, каждая WSS-попытка
  **8 с**, запись **10 с**, idle **60 с**. WS message должен целиком прийти
  за **60 с**. Долгий простой или медленная передача требует переподключения.
- WSS только для upstream default redirects DC 2/4; другие DC идут по TCP.
  DC 203 сохранён; тестовые DC исключены. Domain fronting отсутствует;
  certificate trust и hostname verification обязательны.
- При потере/замене сети сессии закрываются. Wi-Fi/LTE на физическом устройстве,
  бесшовная миграция и IPv6-only не проверены.
- Fake TLS, Cloudflare, WS pools, балансировка и HTTP/2 запланированы.
- `specialUse` обоснован пользовательским постоянным локальным сервисом;
  соответствие правилам магазина отдельно не подтверждено.
- Debug APK имеет отладочную подпись. Доверенная подпись пользовательского
  релиза не предоставлена; секреты подписи в репозиторий не добавлены.

Проверка освобождения порта включает отказ нового TCP connect и повторный bind
с той же политикой `SO_REUSEADDR`, что у production listener. Kernel `TIME_WAIT`
после закрытия принятой сессии не равен оставшемуся слушающему сокету.
