# Проверка 0.1.1-alpha

Дата: 15 октября 2026, UTC. [English](en/TEST_REPORT_0.1.1-alpha.md).

## Пользовательская проверка предыдущей сборки

Пользователь сообщил об успешной отправке, получении и загрузке через прокси
**0.1.0-alpha** на Android 16, Telegram 13.0.2, Wi-Fi. Модель устройства и
commit установленного APK не подтверждены; предложенный CI-артефакт собран
на `c1ef979`. Зафиксированы краткие обрывы и сообщения об ошибках WSS/TCP.
Независимое физическое тестирование разработчиком не выполнялось.

## Воспроизведённые дефекты и исправления

- Тесты живого Ping/Pong, heartbeat после тишины и снятия старой ошибки fallback
  провалились до исправления. После исправления проходят.
- WSS ожидал сообщение с одним абсолютным сроком 60 с, включая все control
  frames. Теперь успешные control frames обновляют ожидание. При тишине 60 с
  отправляется masked Ping (8 случайных байтов); ожидается совпадающий Pong
  до 10 с. Нет ответа — сокет закрывается. Heartbeat не передаётся в MTProto.
- Неполный фрейм/фрагментированное сообщение по-прежнему ограничены сроком 60 с;
  control traffic не продлевает сборку сообщения. Close имеет отдельный срок.
- Предел бездействия MTProto увеличен до 300 с; WebSocket heartbeat не считается
  полезной MTProto-активностью. Иные сроки и лимит 8 клиентов сохранены.
- WebSocket-запись буферизуется максимум на 16 КиБ перед TLS; включён TCP_NODELAY.
  Сертификаты и hostname проверяются как прежде, криптография и маршруты не менялись.
- Новое установленное соединение снимает прошлую ошибку сессии. Ошибки иных
  сессий при активном транспорте видны как последнее событие, без ложного общего
  аварийного статуса. Локальные ошибки не скрываются; добавлены WSS/TCP-счётчики.

## Автоматические проверки

```bash
./gradlew --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest
python3 -m unittest discover -s .github/scripts -p 'test_*.py'
```

Локально: **113 JVM-тестов, 0 failures/errors/skipped**, **16 тестов CI-скриптов**,
Lint и оба APK — успешно. Actionlint проверяет оба workflow. RU/EN: 52 строки
с совпадающими ключами. Существующие тесты сохранены; отрицательный тест молчащего
peer теперь проверяет Ping и закрытие без Pong.

Матрица API 34–37 выполняет 10 инструментальных тестов на каждом API и строго
проверяет реальные JUnit-записи. Результаты: [Android CI](https://github.com/Kust3r3nk0/TGWS-Android/actions/workflows/android-ci.yml)
и [Android device tests](https://github.com/Kust3r3nk0/TGWS-Android/actions/workflows/android-instrumented.yml).

## Что ещё не подтверждено

Исчезновение реальных обрывов в **0.1.1-alpha**, длительная работа, мобильная сеть,
Wi-Fi/LTE-переключения и все причины отказа WSS/TCP. Сбой одного маршрута может
зависеть от сети; локальные тесты не доказывают доступность Telegram из неё.
Нужен повтор на устройстве пользователя: обмен/загрузка, несколько минут простоя,
повторный обмен, сворачивание/возврат и разрыв/восстановление Wi-Fi.

Debug APK имеет отладочную подпись, доверенный пользовательский релиз не готовится.
Tag и Pre-release не создаются. [Исторический отчёт 0.1.0-alpha](TEST_REPORT.md).
