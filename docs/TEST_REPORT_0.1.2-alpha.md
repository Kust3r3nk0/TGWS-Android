# Проверка 0.1.2-alpha

15 октября 2026, UTC. [English](en/TEST_REPORT_0.1.2-alpha.md).

## Изменения

- Логотип владельца: исходный JPEG в README, прозрачный символ в заголовке,
  adaptive launcher icon и монохромный notification icon. Установленное название
  **TGWS-Android**, versionName `0.1.2-alpha`, versionCode **3**.
- Минимальная ОС — **Android 15 / API 35**. compileSdk 37.0, targetSdk 37,
  Kotlin/AGP/Wrapper/JDK сохранены. Текущая матрица: API 35, 36, 37.0.
- Отказ отдельного клиента больше не подменяет глобальную ошибку приложения.
  Счётчик и последняя причина видны отдельно: длина, запрещённый префикс,
  секрет/формат, неподдерживаемый DC. Причина не содержит байтов заголовка,
  секрета, ключей или данных сообщений. Неверный секрет по-прежнему отклоняется.
- Локальные ошибки и ошибки TCP не скрываются отклонёнными заголовками;
  при ожидающих клиентах явно показано, что активный транспорт ещё не установлен.

## Проверки

Обязательная команда с добавленной сборкой instrumentation APK:

```bash
./gradlew --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest
python3 -m unittest discover -s .github/scripts -p 'test_*.py'
```

Локально полный Gradle-прогон прошёл: **117 JVM-тестов, 0 failures/errors/skipped**.
Lint: 0 ошибок, 3 прежних UseKtx-предупреждения. Чистая сборка без build cache также прошла; повреждённый локальный cache после перемещения ресурса не использовался для проверки. Сохранены 36 эталонных handshake/crypto векторов. Новые тесты проверяют причины
отказа и неизменность решения accept/reject, отсутствие ложного сбоя listener,
сохранение сетевых ошибок и ограничение счётчика. **16 тестов CI-скриптов** прошли.

Матрица API 35–37 требует **11** инструментальных тестов на каждом API, включая
реальное разрешение adaptive icon, installed label/minSdk и отображаемое состояние
после отклонения заголовка. Пустые/неполные JUnit-отчёты не засчитываются.
Результаты доступны в [GitHub Actions](https://github.com/Kust3r3nk0/TGWS-Android/actions).

## Наблюдение пользователя и ограничения

Пользователь сообщил, что **0.1.1-alpha** работает, а Telegram показывает 6–8 мс.
На скриншоте одновременно 0 установленных транспортов, 1 ожидающий клиент и
последний отказ handshake. Скриншот не определяет причину отказа или текущий
путь трафика; ping может относиться к другому моменту/проверке клиента.
Проверка секрета не ослаблялась, совместимость нового неизвестного варианта не заявляется.

Новый APK требует повторного физического теста. Полный E2E, длительная работа,
мобильная сеть и восстановление Wi-Fi/LTE независимо не проверены.
Владелец разрешил публикацию **debug-предрелиза**, без заявления о стабильности.
Подпись отладочная; постоянная CI-подпись не настроена из-за отсутствия доступа
интеграции к Actions secrets (HTTP 403). Не публикуются ключи подписи.
