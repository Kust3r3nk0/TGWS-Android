# TGWS-16-017 — responsibilities

Codex develops/fixes the app, runs unit/integration/CI/Lint/build checks and provides a Debug APK with version, source/tree SHA, checksum and changelog.

The owner performs physical checks. Never seek phone/ADB access. Feedback stays in the development chat; personal reports, device/carrier/region details are not published in the app, repository, PRs or releases.

Public issues contain anonymous reproduction steps and technical error categories only. Never include secrets, private URLs or messages. CI evidence describes CI and does not certify a phone. Debug publication requires automated gates; stable release requires resolved critical issues and trusted signing. No embedded WebView.
