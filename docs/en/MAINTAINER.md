# Maintainer checklist

Android CI builds a debug APK and runs JVM tests and lint. Validate the app on real Android 14+ devices before claiming working connectivity or a stable release. Enable Issues, Dependabot alerts, and private vulnerability reporting. Consider branch protection after CI succeeds.

Recommended topics: android, kotlin, jetpack-compose, telegram, mtproto, websocket, open-source. Do not release signed packages or claim production readiness before proper verification.
