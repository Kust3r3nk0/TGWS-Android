# TGWS-Android 0.6.1 — Connection Recovery · Debug

Android 16+ / API 36+, code 23. Debug Pre-release, not Production.

## Fixes

- Reserve time for a configured Worker/origin relay behind failed speculative routes, including media DCs.
- Preserve the last permitted dial admission for that configured endpoint.
- Retain total deadline, TCP reservation, backoff, Retry-After and manual permissions.

## Technical

- Regressions cover both reproduced failures and strict MANUAL permissions.
- Retain 0.6.0 features, UI, settings, secret, Keystore, Android DNS and strict TLS.
- Worker/Node code is unchanged from 0.6.0; no redeploy required. Worker remains capped at 16 MiB/session.

## Important

Install over a compatible signed Debug APK without uninstalling. Device Telegram
and HD-media stability must be checked by the owner. Automated reproductions do
not establish that every external network failure has been resolved.
