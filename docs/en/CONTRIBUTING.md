# Contributing

Thanks for supporting TGWS-Android. Open an Issue before substantial changes, keep Android 14+ compatibility, use stable dependencies, provide tests and preserve upstream Flowseal attribution.

Never commit live MTProto secrets, API tokens, private logs, signing certificates or personal data.

Before submitting a PR, run `gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`, explain what changed, include test results and update documentation. The project does not yet include the Gradle wrapper JAR.
