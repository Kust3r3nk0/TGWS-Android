# Contributing

Thanks for supporting TGWS-Android. Open an Issue before substantial changes, keep Android 15+ compatibility, use stable dependencies, provide tests and preserve upstream Flowseal attribution.

Never commit live MTProto secrets, API tokens, private logs, signing certificates or personal data.

Before submitting a PR, run `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`, explain what changed, include test results and update documentation. The project includes Gradle wrapper scripts and the official wrapper JAR.
