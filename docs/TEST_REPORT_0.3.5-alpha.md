## Ограничения и проверка владельцем

TGWS-16-016: Compose/MTProto нативные, встроенного WebView нет. CI записал до/после `com.google.android.webview`: API 36 — `133.0.6943.137`, API 37 — `145.0.7632.218`; `latest_verified=false`. Это инвентаризация эмуляторов, не подтверждение актуальных Stable/Beta. One UI и физические сценарии не проверены.

TGWS-16-017: физические Telegram, Wi-Fi/LTE, One UI и Stable/Beta проверяет владелец. Для 0.3.5 результаты ожидаются. Устанавливайте поверх предыдущего debug-релиза без удаления данных. После запуска проверьте текущую Telegram-ссылку, текст/SD/HD, восстановление сети и 30–60 минут с выключенным экраном. При ошибке передайте обезличенный экспорт с категорией, кодом Close и счётчиками маршрута; секрет и адрес реле не присылайте.

Причина 2529 отказов на телефоне не установлена; исправлены воспроизводимые пути рассинхронизации настроек и ложной диагностики. Доступность узла у оператора не гарантируется. Worker сохраняет 16 МиБ на сессию; увеличение до 24 МиБ используется только тестом. HD-upload и внешние транспорты не объявляются исправленными без E2E. [Условия стабильного выпуска](STABILITY_GATE.md).
