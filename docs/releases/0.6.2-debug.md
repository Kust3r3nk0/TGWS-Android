# TGWS-Android 0.6.2 — Автонастройка сети · Debug

Android 16+ / API 36+, code 24. Тестовый Pre-release.

## Новые функции

- Настройки → Smart Connection → «Автонастройка текущей сети»: одна кнопка запускает ограниченную проверку разрешённых маршрутов и сохраняет профиль Wi-Fi/мобильной сети.
- Проверяется ответ req_pq_multi от DC 2: Obfuscated2, размер/тип resPQ и nonce, а не только TCP/TLS/Upgrade. Это проверка доступности MTProto без аккаунта, не авторизация Telegram и не измерение ping.
- Основной транспорт выбирается по успешному ответу и времени полного обмена; разрешённые резервные маршруты сохраняют backoff и право последующего восстановления.
- Видны прогресс, категории отказов и HTTP-коды; проверку можно отменить.

## Исправления

- Учёт входящего трафика до передачи клиенту устраняет гонку финального счётчика при остановке после крупного файла.

## Важное

Остановите прокси перед автонастройкой. Приложение использует только настроенные адреса и разрешённые транспорты текущего режима; «Только реле» не обходит запрет прямого подключения. Секрет, локальный порт и Fake TLS/SNI не подбираются случайно и не меняются: их изменение нарушило бы ссылку Telegram. Тема и остальные пользовательские настройки сохраняются.

Проверка занимает до 60 секунд, до 8 секунд на маршрут, без фонового повторения; повторный запуск не чаще раза в минуту. Смена сети, уход с экрана или сворачивание отменяют проверку и закрывают ресурсы. Без успешного ответа прежняя конфигурация сохраняется. При ошибке сохранения показывается ошибка, черновик восстанавливается.

Проверяются до двух разрешённых узлов каждого настроенного вида; сначала один кандидат каждого вида. HTTP/2 media не проверяется и не выбирается основным. Успех DC 2 не гарантирует остальные DC, HD-медиа или отсутствие ограничений Worker (16 МиБ/сессию). Успешный Worker перемещается первым в сохранённом списке; успешный VPS становится основным среди разрешённых узлов — эти приоритеты адресов общие для профилей. Сами адреса не создаются и не удаляются. Профили различают тип сети, а не конкретный SSID/оператора.

Автонастройка не создаёт внешнее реле и не снимает блокировку, если ни один разрешённый маршрут не доступен. В таком случае показаны причины отказов. Worker/Node относительно 0.6.0 менять не требуется. Установить APK поверх совместимой подписанной Debug-сборки без удаления приложения; проверить запуск, переключение сетей и Telegram. Физическую проверку выполняет владелец, без публикации личных данных.
