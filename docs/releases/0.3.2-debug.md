# TGWS-Android 0.3.2 Debug — Android 15+

Liquid Glass · бета. Включение: **Настройки приложения и MTProxy → Оформление → Liquid Glass**.
По умолчанию выключен, в том числе после обновления. Выбор сохраняется сразу;
перезапуск прокси не нужен. Светлая/тёмная темы: стеклянные панели и навигация,
мягкий сине-бирюзовый фон, блики и преломление по краям.

Нативный RuntimeShader Android без новых зависимостей, захвата экрана или постоянной
анимации. Преломляется процедурный фон; полного преломления произвольного UI нет.
Настройки подключения, DNS, applicationId и debug-сертификат сохранены.

versionName `0.3.2-alpha`, versionCode 8. Это тестовый Pre-release с debug-подписью,
не production-релиз. Checksum, commit и результаты проверок приложены.
Проверка владельцем на физическом устройстве: ожидается, включая внешний вид,
батарею, мобильную сеть и Telegram. Гарантия обхода блокировок не заявляется;
прежний Worker сохраняет лимит 16 MiB/сессию.

English: Optional Liquid Glass beta under Settings → Appearance; off by default,
persistent and immediate. Frosted panels/navigation in both themes using a native
static procedural shader. Proxy/DNS configuration and debug certificate preserved.
Debug prerelease; physical appearance/performance and Telegram/carrier validation pending.
