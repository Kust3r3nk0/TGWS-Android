# TGWS-Android 0.6.0 — Relay & Performance Update · Debug

Android 16+ / API 36+, code 22. Тестовая подпись сохранена для установки поверх
совместимых Debug APK без удаления приложения. Это Pre-release, не Production.

## Новые функции

- Менеджер до 8 собственных WSS/VPS-реле: зашифрованные URL, названия, основной и разрешённые резервные узлы.
- Ручной, резервный и автоматический выбор по данным Smart Routing; только новые сессии, без replay.
- Ручная проверка узлов, HTTP/категории отказов и отмена при фоне/смене сети.
- Media-разрешения узлов и выключенное по умолчанию предпочтение собственного реле для media DC.

## Исправления

- VPS-реле обновляет тайм-аут после каждой ограниченной записи, сохраняя backpressure.
- Слот подключения освобождается после подтверждённого закрытия TCP/WS; shutdown закрывает незавершённый TLS.
- Уведомления о резерве различают разные узлы одного транспорта; приватные адреса в журнал не попадают.

## Техническое

- WorkManager 2.12.0, Core KTX 1.19.1, JSON-java 20260814 (только тесты), setup-java 6.1.0 по commit SHA: изменения PR #27–30.
- Старые настройки, secret, Keystore, темы, DNS Android и TLS-проверки сохранены.
- Сценарий VPS-развёртывания, systemd unit, ограниченные переменные среды и инструкция обновления с сохранением токена/TLS.

## Важное

Менеджер включается явно: Настройки → Транспорт → Менеджер VPS-реле. После добавления
сохраните настройки. Прямой режим не использует реле; MANUAL/«Только реле» не обходят
выбранные ограничения. Уже начатый поток не переносится на другой сервер.
Обновите собственное Node.js-реле для серверных исправлений; APK сервер не обновляет.
Worker остаётся прежним: 6 сессий/isolate и 16 МиБ/сессию. Исправленный Worker 0.4.2
не требует redeploy. Работа реального Telegram/HD/mobile проверяется владельцем.
