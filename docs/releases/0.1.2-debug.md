Тестовый **Debug-предрелиз** для **Android 15+ (API 35)**. Это не стабильный production-релиз.

- Логотип владельца, adaptive/themed icon, название приложения **TGWS-Android** без Alpha.
- Отклонённые клиентские заголовки учитываются отдельно от ошибок сервера/сети; видны категории отказа, strict secret/protocol validation сохранена.
- Сохранены WSS heartbeat, TCP fallback, TLS certificate/hostname verification, лимиты ресурсов и защищённое хранение секрета.
- Версия внутри приложения: 0.1.2-alpha, versionCode 3. Android 14 этой версией не поддерживается.

Проверки: 117 JVM-тестов, 16 тестов CI-скриптов, Lint без ошибок; API35/36/37: по11 инструментальных тестов, все33 выполнения прошли без ошибок/пропусков. Точные результаты и commit — в приложенных REPORT.md/build-info.json.

Пользователь подтвердил работу прежних 0.1.0/0.1.1 на Android16 / Telegram13.0.2 / Wi-Fi; 6–8мс — показание Telegram. Новую версию на физическом устройстве независимо не проверяли. Длительная стабильность, полное восстановление Wi-Fi/LTE и все маршруты не подтверждены. Fake TLS, Cloudflare, HTTP/2, IPv6-only не поддерживаются.

**Установка:** скачайте TGWS-Android-0.1.2-debug.apk. APK подписан сохранённым debug-ключом этой рабочей среды; CI-артефакты имеют другую подпись. При переходе со старой CI-версии сохраните ссылку/секрет, удалите её и установите этот APK. Следующие debug-релизы следует подписывать тем же сохранённым ключом. Не используйте debug-подпись как доверенную production-подпись.

Если Telegram хранит несколько старых локальных прокси с прежними секретами, их проверки могут порождать отклонения handshake при работающей актуальной записи. Сверьте ссылку; секрет никому не отправляйте.

Исходники зафиксированы тегом этого предрелиза; подготовка main ведётся в PR #2. Секреты и signing key не входят в assets.
