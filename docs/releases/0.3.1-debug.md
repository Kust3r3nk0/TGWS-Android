# TGWS-Android 0.3.1 Debug — Android 15+

Тестовый Pre-release: versionName `0.3.1-alpha`, versionCode 7.

- Две нижние вкладки: «Главная страница» и «Настройки приложения и MTProxy».
  Сохранены параметры подключения, добавлено сохранение без запуска сервиса.
- Material 3, тёмная/светлая/системная темы с сохранением и быстрым переключателем в меню.
- Выбираемый Cloudflare DNS-over-HTTPS: 1.1.1.1/1.0.0.1 и IPv6, A/AAAA,
  строгий TLS, конечные сроки, ограничение ответа и явная отмена при stop/смене сети.
- Wi-Fi/мобильная/другая сеть и IPv4/IPv6/dual-stack автоматически видны на главной,
  включая остановленный прокси. Link-local не выдаётся за доступное интернет-семейство.
- Прежние MTProto/транспортные тесты сохранены; добавлены DoH, UI/темы/сохранение и снимки экранов.

Системный DNS сохранён по умолчанию; Cloudflare выбирается в настройках. Он действует
только внутри приложения, не меняет DNS Android и не гарантирует обход IP-блокировки.
В IPv6-only с операторским DNS64 может потребоваться системный resolver.

APK подписан прежним debug-сертификатом для обновления поверх предыдущей сборки.
Это не production-подпись. Приложены checksum, commit, build-info и отчёты.
**Проверка владельцем на физическом устройстве: ожидается.** Реальные Cloudflare,
мобильный интернет и Telegram этой версии не проверены. Прежний Worker сохраняет лимит 16 MiB/сессию.

English: Material 3 Home/settings navigation, persistent light/dark/system themes,
optional app-scoped Cloudflare DoH and automatic network/IP-family display.
System DNS and proxy configuration are preserved. Debug signing; owner physical validation pending.
