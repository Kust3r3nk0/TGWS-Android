# TGWS-Android 0.4.2 — Relay Stability Fix · Debug

Тестовая сборка Android 16+ / API 36+, versionCode 20. Debug-подпись сохранена
для обновления поверх предыдущих тестовых APK; это **не Production-релиз**.
Не удаляйте приложение перед обновлением. При несовместимой подписи не продолжайте установку.

## Исправления

- Ранние обрывы после Upgrade учитываются в backoff; повторы одной попытки
  и поздний EOF прежней сети не искажают бюджет восстановления.
- Перегрузка одного Worker учитывается совместно для DC, с ограниченной паузой
  и одной проверкой восстановления. Лимиты защиты Worker сохранены.
- Close-код и безопасная причина сохраняются даже при неудачном ответе echo.
- Клиентский EOF отправляет WS Close до освобождения raw-сокетов;
  stop/network/deadline немедленно закрывают native TCP и связанные ресурсы.
- Устранены утечка stream-lock при неудавшемся Upgrade и преждевременный
  повторный допуск до завершения закрытия upstream TCP.
- Ошибка одной сессии не меняет состояние других работающих сеансов маршрута.
- Автоматический режим больше не расширяет setup budget до 40 с; ограниченные
  WSS-попытки оставляют время для разрешённого TCP fallback.
- INVALID_LENGTH больше не вызывает подсказку о неверном секрете: неполный
  заголовок и ошибка аутентификации различаются.

## Техническое

- Подробности HTTP Upgrade, fixed Worker categories, Retry-After и завершение
  отдельных сессий в журнале/JSON schema 3. Приватные адреса и текст исключений исключены.
- Записи о завершении сохраняются при остановке Android Service, до удаления callbacks.
- Отдельный CI-артефакт Worker с модулем, checksum и commit сборки.
- В артефактах релиза — APK, SHA256SUMS, build-info.json, update-manifest.json,
  changelog и проверенный CI-модуль `TGWS-Cloudflare-Worker-0.4.2.zip`.
- Это ревизия 2 (code 20): старый `v0.4.2-debug` / code 19 не перезаписывается.

## Важное

Обновите **APK и существующий Cloudflare Worker**:
[пошаговая инструкция](https://github.com/Kust3r3nk0/TGWS-Android/blob/feature/0.4.2-relay-stability/docs/RELAY_STABILITY_0.4.2.md).
Токен Worker, домен, MTProto secret и настройки менять не нужно.
Установка APK сама по себе не обновляет Worker в Cloudflare.

6 сессий/isolate, 16 МиБ суммарно/сессию, очередь 4 МиБ + 4 Б и 64 сообщения
остаются в силе. Большие медиа могут достигать BYTE_LIMIT; непрерывная передача
через Worker без drain/flow-control не обещается. Автоматические проверки
не заменяют испытания внешнего узла/Telegram владельцем на устройстве.
