# TGWS-Android 0.4.0 — Premium Minimal

Кандидат на стабильный выпуск для Android 16+. Production-публикация зависит от доверенной Release-подписи и подтверждения владельца. Тестовый Debug APK не является Production.

## Новые функции
- Три вкладки: Главная, Диагностика и Настройки; отдельные подразделы подключения, транспорта, оформления и обновлений.
- Продолжительность работы службы, счётчики трафика и сессий, график фактического времени установки транспорта.
- Локальный журнал до 128 событий и 32 замеров с отключением и очисткой; секреты и адреса в него не попадают.

## Исправления
- Черновики настроек переживают поворот Activity в памяти, без записи открытых секретов в savedInstanceState.
- Системная кнопка «Назад» возвращает из подразделов и не останавливает прокси.

## Оптимизация
- Таймер диагностики работает только при открытом экране и активном lifecycle; активные сетевые пробы запускаются явно.
- История ограничена, журнал не записывается на диск, отключённые эффекты не запускают shader.

## Техническое
- Общие токены Premium Minimal, оригинальный tgws_symbol, светлая и тёмная темы; Update Center приведён к общей палитре.
- versionCode 17, minSdk 36; параметры сетевого ядра, системный DNS и криптографическая проверка обновлений сохранены.
- Отдельная Release-конфигурация без Debug-подписи; CI проверяет неподписанный кандидат, ручной workflow проверяет доверенный сертификат до передачи Production-кандидата.

## Важное
- Совпадение applicationId не обеспечивает совместимость разных подписей. Новый независимый Release-ключ без проверенной цепочки ротации не может обновить прежний Debug APK поверх установки и не наследует его Keystore. Поддержку такой миграции не заявляем; удалять приложение автоматически запрещено.
- Время установки транспорта не является ping Telegram. Сетевые ограничения и доступность внешних реле зависят от сети.
- Физические проверки выполняет владелец; личные сведения не публикуются. Известный сценарий HD-медиа требует проверки на реальном маршруте.
