# TGWS-Android 0.3.0 Debug — Android 15+

Тестовый **Pre-release**, versionName `0.3.0-alpha`, versionCode 6.
**Проверка владельцем на физическом устройстве: ожидается.**

- Fake TLS: HMAC hello/response, record framing, импорт/создание `ee`-ссылок.
- Отдельные direct, relay-only и Auto CF; Worker → CF Proxy → TCP с ограниченными
  попытками/ротацией/backoff. Relay-only сохраняет запрет прямого fallback.
- HTTP/2 для совместимых CF media `/api`: настоящий TLS/ALPN `h2`, независимые
  native-сессии, flow control, ограниченные очереди, RST/GOAWAY/cancel без replay.
- DNS/сокеты активного Android Network, IPv4/IPv6, очистка при смене сети;
  справочник МегаФон/МТС/билайн/T2 без изменения APN, DNS или SIM.
- Диагностика маршрутов/сети/трафика, реальные setup-замеры, ручная проверка
  и обезличенный экспорт с предпросмотром. Keystore migration сохраняет режим 0.2.
- Прежние и новые протокольные/Android-тесты, два обязательных 60-секундных
  CI soak (TCP/WSS и полный MTProto/TLS/H2), матрица API 35/36/37.

Установка поверх прежнего debug APK сохраняет package и прежний debug-сертификат.
Это **не production-подпись**. Checksum, исходный commit, build metadata, changelog
и проверенные отчёты приложены к релизу.

Внешние CF/Worker → Telegram, мобильные операторы, реальный IPv6-only и длительный
screen-off ожидают проверки владельца. Локальный Fake TLS не снимает IP-блокировку.
CF Proxy/H2 требует вашего совместимого сервера; экспериментальный Worker сохраняет
лимит **16 MiB на сессию**, который может прерывать большие загрузки. Бесшовная миграция,
автозагрузка списков доменов и тестовые DC не заявляются.
