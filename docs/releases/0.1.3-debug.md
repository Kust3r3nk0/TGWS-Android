# TGWS-Android 0.1.3 Debug — Android 15+

Тестовый **Pre-release**, versionName `0.1.3-alpha`, versionCode 4.

- Добавлено поле собственного WSS-реле: альтернативный IP для сетей, где прямые
  адреса Telegram недоступны. Непустое поле включает только реле; пустое сохраняет
  прежние WSS/TCP маршруты. Локальную ссылку Telegram менять не требуется.
- Контракт Flowseal Worker `dst`/`dc`, строгий TLS, отдельный счётчик сессий.
  URL с ключом пути скрыт и зашифрован Keystore AES-256-GCM.
- Ограничены ожидание DNS и resolver-потоки. Добавлены тесты отказов, тайм-аутов,
  маршрутов, криптографии, сохранения настроек и локального TLS/WSS/TCP реле.
- В репозитории есть сервер собственного реле и
  [инструкция](https://github.com/Kust3r3nk0/TGWS-Android/blob/codex/alpha-core-hardening/docs/MOBILE_NETWORKS.md).

**Требуется ваш доступный внешний узел.** Реле не развёрнуто автоматически;
публичные чужие узлы не добавлены. Работа через реального мобильного оператора
и внешнее реле → Telegram **не подтверждены**. Прямой режим ранее работал по
сообщению владельца на Wi-Fi; это не проверка нового маршрута.

APK подписан тем же сохранённым debug-ключом, что 0.1.2 Debug, для обновления
поверх него. Это не production-подпись. Приложены checksum, commit и отчёты
автоматических проверок. Для стабильного релиза остаётся полный release gate.
