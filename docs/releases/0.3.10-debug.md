## Новые функции

- Нативный TGWS Update Center и отдельные настройки автоматической проверки.
- Явный выбор Stable/Preview, расписание WorkManager, уведомления и Wi-Fi-only для APK.
- Прогресс, отмена загрузки и установка через подтверждение Android.

## Исправления

- Проверка SHA-256, полной подписи APK, версии, package name и допустимой ротации ключа перед установкой.
- Сохранение результата проверки и повторная проверка файла после восстановления приложения.

## Техническое

- Android 16+, версия 0.3.10-alpha, versionCode 16. Сетевое ядро 0.3.9 сохранено.
- Поддерживается документированный update-manifest.json и категории Release Notes; прежние релизы без метаданных не предлагаются автоматически.
- Сохранены debug-сертификат, MTProto secret, Keystore и параметры приложения.

## Общее сведение

Предварительная Debug-сборка. Прежний Worker сохраняет ограничение 16 МиБ/сессию; доступность внешнего узла зависит от сети.
