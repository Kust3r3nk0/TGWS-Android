# TGWS-Android 0.6.1 — Connection Recovery · Debug

Android 16+ / API 36+, code 23. Debug Pre-release, не Production.

## Исправления

- Настроенный Worker/собственное WSS-реле получает резерв времени после неудачных пробных маршрутов, включая media DC.
- Неудачные Cloudflare-кандидаты не расходуют последнюю разрешённую попытку перед настроенным реле.
- Сохранены общий deadline, резерв TCP, backoff, Retry-After и ограничения ручного режима.

## Техническое

- Регрессионные тесты двух воспроизводимых отказов и запрета скрытого fallback в MANUAL.
- Сохранены функции 0.6.0, UI, secret, Keystore, зашифрованные настройки, Android DNS и строгий TLS.
- Серверный код не менялся: повторно развёртывать Worker/Node относительно 0.6.0 не нужно. Worker сохраняет 16 МиБ/сессию.

## Важное

Устанавливайте поверх совместимого Debug APK без удаления приложения. Сохранённая
тестовая подпись не является Production-подписью. Реальную устойчивость Telegram
и HD-медиа подтверждает владелец; исправлены воспроизведённые автоматическими
тестами сценарии, а не все возможные сетевые ограничения.
