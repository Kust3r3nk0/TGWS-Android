TGWS-Android 0.3.5 — проверяемое обновление надёжности для Android 16+.

- Сохранение секрета и настроек перед передачей ссылки Telegram; корректная вставка dd/ee.
- Явное восстановление при пропавшей зашифрованной записи вместо молчаливой генерации.
- Точная классификация неполного handshake/тайм-аутов и нормальных TCP-проверок.
- Корректное завершение Android Service и отображение истории отказов.
- Устранение гонки закрытия сокетов при остановке и смене сети.
- Диагностика медиа PR #16: трафик по маршрутам и безопасные категории закрытий; CLOSED вместо устаревшего READY.
- CI-регрессия установки поверх 0.3.4 с сохранением Keystore и настроек.

Проверки: 203 JVM-теста, Lint без ошибок, по 33 Android-теста и успешное обновление поверх 0.3.4 на API 36/37, 11 тестов WSS-реле и 17 Worker-тестов. Работу с Telegram, операторами, One UI и WebView Stable/Beta подтверждает владелец по TGWS-16-017. Доступность внешнего реле у оператора этим обновлением не гарантируется. Это Pre-release, стабильный release gate ещё не пройден.

Экспериментальный Worker сохраняет лимит 16 МиБ/сессию. Обновлённый код Worker не развёртывается автоматически; его APK-диагностика не подтверждает исправление HD-загрузок.
