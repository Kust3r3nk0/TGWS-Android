# TGWS-Android 0.3.4 Debug — Android 15+

Встроенный DNS Cloudflare удалён из меню, сетевого ядра и пользовательского APK.
Используется DNS активной сети Android (системный Private DNS/сетевые DNS64-ответы).
Старое предпочтение DNS удаляется без сброса порта, секрета, реле, тем или эффектов.
Генерировать новый secret/ключ Worker после обновления не требуется.

TCP-подключения пробуют IPv4/IPv6 с шагом 250 мс, максимум две попытки одновременно,
общим deadline и закрытием проигравших сокетов. Отказы DNS/TCP/TLS/deadline различаются
в диагностике. Настроенные Worker/Cloudflare/H2 сохраняются; проверка TLS обязательна.
Прежние DoH-тесты перенесены в test-only fixtures и не включаются в APK.

Добавлены WebView-контракт TGWS-16-016 и порядок физических проверок TGWS-16-017:
UI/MTProto нативные, WebKit без необходимости не добавлен; CI фиксирует provider/version
эмулятора, APK-артефакт содержит OWNER_HANDOFF.md с версией/SHA/ссылкой на запуск.

versionName `0.3.4-alpha`, versionCode 10, applicationId и прежний debug-сертификат сохранены.
Это тестовый Debug Pre-release, не стабильный production-релиз. Владелец сообщил об отказах
предыдущей версии во всех режимах; **работа этой сборки у операторов пока не подтверждена**.
DNS не отменяет IP/SNI/allowlist ограничения. При блокировке нужен доступный внешний узел;
приложение не создаёт его автоматически. Worker сохраняет лимит 16 MiB/сессию.

English: Removed built-in Cloudflare DNS, migrated only the obsolete preference, preserved all
other configuration and configured transports. Bounded IPv4/IPv6 TCP attempts (250 ms/two in
flight), cleanup and safe layered diagnostics. Historical DoH tests are fixture-only.
Native WebView applicability/CI inventory and owner-only physical testing handoff included.
Preserved debug certificate; carrier/Wi-Fi/Telegram validation awaits the owner. No universal bypass.
