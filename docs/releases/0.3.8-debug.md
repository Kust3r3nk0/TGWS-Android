TGWS-Android 0.3.8 — Debug, Android 16+.

Удалены личные отчёты из приложения, репозитория и метаданных сборки. Настройки, секрет и applicationId сохраняются. Сетевые ошибки Obfuscated2, HD-фото/кружков и восстановления сети остаются в работе; их исправление этой сборкой не заявляется.

Обновление устанавливается поверх 0.3.6/0.3.7 с прежним debug-сертификатом, без удаления данных. Это Pre-release, не стабильный production-релиз.
