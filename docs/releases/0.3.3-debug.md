# TGWS-Android 0.3.3 Debug — Android 15+

Добавлен отдельный **«Эффект прозрачности»**: Настройки приложения и MTProxy → Оформление.
По умолчанию выключен. Выбор сохраняется сразу, перезапуск прокси не нужен.
Можно использовать без Liquid Glass или вместе с ним; переключатели независимы.

Фон приложения действительно просвечивает сквозь карточки и панели; текст и кнопки
остаются непрозрачными. Нативный Android shader с premultiplied alpha. Основное окно
непрозрачное, обои и другие приложения не захватываются. Новых разрешений, зависимостей
и постоянной анимации нет. Это бета-оформление в стиле Liquid Glass, не технология Apple.

versionName `0.3.3-alpha`, versionCode 9. Прежние параметры подключения/DNS, applicationId
и debug-сертификат сохранены. Тестовый Pre-release, не production-релиз; checksum,
commit и результаты проверок приложены.

Проверка владельцем на физическом устройстве: ожидается, включая внешний вид, батарею,
мобильную сеть и Telegram. Обход блокировок не гарантируется; Worker по-прежнему
ограничен 16 MiB/сессию.

English: Separate Transparency effect under Settings → Appearance, off by default, persistent
and independent of Liquid Glass. Actual panel alpha blending, opaque text/controls, both themes.
Root window stays opaque; no extra dependencies/permissions or continuous animation.
Preserved debug certificate; physical appearance/battery/Telegram/carrier validation pending.
