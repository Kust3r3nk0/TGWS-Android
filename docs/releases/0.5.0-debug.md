# TGWS-Android 0.5.0 — Smart Connection Update · Debug

Android 16+ / API 36+, code 21. Debug Pre-release с сохранённой тестовой подписью.
Устанавливайте поверх совместимой версии без удаления приложения. Production gate
и физическая устойчивость Telegram не заявляются.

## Новые функции

- Smart Routing: автоматический, ручной и основной/резервный транспорт для новых сессий.
- Профили Wi-Fi, мобильной сети, автоматический и пользовательский; разрешения,
  приоритет, резерв, адаптивное восстановление и энергосбережение.
- Health Monitor с реальными setup/outcome/DC/media и причинами выбора маршрута.
- График фактического трафика и необязательные уведомления о длительном сбое/восстановлении.

## Исправления

- Старые сессии закрываются до инвалидирования фабрики при смене сети.
- Одинаковые own/Worker endpoints не обходят cooldown и не расходуют две попытки.
- Итоговые байты сохраняются после остановки; скорость остановленного прокси равна нулю.

## Оптимизация

- Пассивная ограниченная статистика с затуханием, без постоянных сетевых тестов.
- Энергосбережение отключает прогрев WSS; восстановление сохраняет защитный backoff.
- 60 точек графика в памяти, до одной/секунду, без невидимой фоновой отрисовки.

## Важное

Smart выключен по умолчанию, старые секреты/ключи/настройки сохраняются.
Включение: Настройки → Транспорт → Smart Connection; прокси предварительно остановить.
Рабочий сокет не подтверждает Telegram; активные MTProto-байты не переигрываются.
Worker не изменён относительно 0.4.2: уже обновлённый узел не требует deploy.
Лимит 16 МиБ/сессию и 6 сессий/isolate сохранён; крупные медиа проверяйте также
через совместимое собственное WSS-реле. Не обещается исправление всех мобильных сетей.
