# TGWS-Android 0.2.0 Debug — Android 15+

Тестовый **Pre-release**, versionName `0.2.0-alpha`, versionCode 5.

- Ограниченный пул ещё не использованных прямых WSS-подключений, ротация по
  возрасту и проверка Ping/Pong перед выдачей. Активные MTProto-сессии не переиспользуются.
- Backoff после setup-отказов: 1–30 с, одна пробная попытка, сброс при смене сети.
  Прямой fallback и relay-only режим сохраняются; пакеты повторно не проигрываются.
- Тесты поздних сокетов, отмены, ротации, сохранения CTR и локальный нагрузочный
  стенд с настоящими TCP/TLS/WSS и ef/ee/dd. Зависимости и эталон Flowseal v1.11.2 сохранены.
- [Политика пула и ограничения](https://github.com/Kust3r3nk0/TGWS-Android/blob/codex/0.2-reliability/docs/RELIABILITY_0.2.md).

APK использует сохранённый debug-сертификат 0.1.2/0.1.3 для обновления поверх них.
Это не production-подпись. Приложены checksum, commit, build metadata и результаты
проверок. Реальный Telegram 0.2.0 на физическом устройстве, продолжительный
Wi-Fi/LTE и внешний relay → Telegram **не проверены**. Реле требует вашего
доступного узла; версия не обещает автоматический обход IP-фильтрации оператора.
