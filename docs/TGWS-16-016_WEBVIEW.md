# TGWS-16-016 — WebView Stable / Beta

Приоритет P1. Требование владельца от 16.10.2026. Матрица Android 16+, AOSP и Samsung
One UI 8.5/9.0; минимум всего приложения — Android 16 / API 36.
[English](en/WEBVIEW_COMPATIBILITY.md) · [порядок физических проверок](TGWS-16-017_PHYSICAL_TESTING.md).

## Применимость к текущему приложению

Аудит 0.3.4-alpha: **встроенных WebView-компонентов нет**. `MainActivity` использует
Jetpack Compose/Material 3; `tg://proxy` открывается внешним `ACTION_VIEW` Intent.
Сетевое ядро — Kotlin/Java sockets, TLS и OkHttp, без браузера и JavaScript.
В production-исходниках/manifest и объявленных зависимостях нет WebView, WebKit или JS bridge.

Поэтому AndroidX WebKit **не добавляется**, WebView не создаётся, renderer callbacks,
восстановление веб-страницы и WebView feature checks сейчас **неприменимы**.
Это не заявление, что последние Stable/Beta или One UI уже протестированы.
Обновление системного компонента не меняет формат конфигурации TGWS; фактический сценарий
обновления провайдера на смартфоне должен подтвердить владелец. Android вправе завершать
процессы; непрерывность сервиса при любом системном обновлении не гарантируется.

CI-проверка `.github/scripts/verify_native_ui.py` контролирует production-исходники,
ресурсы и объявленные Gradle-зависимости. Новая явная WebView-интеграция или JS bridge
останавливают gate до пересмотра этого контракта и реализации требований ниже.
Это проверка деклараций, не анализ всех DEX/рефлексии и не полный аудит безопасности.

## Если встроенный WebView действительно понадобится

Обязательные каналы — последний доступный **Stable и Beta**, Dev — дополнительная
регрессия, Canary — эксперимент без гарантий. Контрольная стабильная зависимость из ТЗ:
`androidx.webkit:webkit:1.17.1`. Перед подключением проверить её доступность/стабильность
и совместимость; будущие стабильные обновления принимать только после автоматических тестов.
RC/Beta/Alpha AndroidX в основной сборке не подключать без отдельного обоснования.

- Через `WebView.getCurrentWebViewPackage()` получать package/version без создания скрытой страницы;
  отдельно обрабатывать отсутствие/невозможность прочитать провайдера.
- Каждую необходимую возможность проверять `WebViewFeature.isFeatureSupported()` или
  соответствующей startup-feature проверкой до использования. Версия пакета не заменяет эти проверки.
- Обрабатывать завершение renderer (`onRenderProcessGone`): удалить повреждённый экземпляр,
  безопасно пересоздать веб-интерфейс, восстановить только допустимое состояние. Не переносить
  MTProto secret в страницу/JS bridge или состояние WebView.
- После смерти процесса восстанавливать конфигурацию из защищённого хранилища; не заменять
  секрет молча. UI/renderer не владеют MTProto-сокетами, запуск сервиса остаётся пользовательским.
- JavaScript выключен, пока не доказана необходимость; доверенные переходы ограничены.
  Небезопасный доступ к локальным файлам запрещён; Safe Browsing/TLS не отключать.
  Не создавать небезопасные JS-интерфейсы, не игнорировать SSL errors.
- WebView не участвует в MTProto transport, не передаёт proxy payload через JavaScript,
  не работает скрыто для фоновой передачи. Ядро остаётся нативным.
- До выпуска измерить RAM, CPU, cold start и батарею веб-интерфейса относительно нативной базы;
  реальные энергозамеры на смартфоне выполняет владелец.

## Матрица подтверждения

| ОС/среда | Провайдер | Обязательность | Встроенный WebView сейчас | Физическая регрессия приложения |
|---|---|---|---|---|
| Android 16 / AOSP | Latest Stable | Обязательно | Не используется | Ожидается от владельца |
| Android 16 / AOSP | Latest Beta | Обязательно | Не используется | Ожидается от владельца |
| One UI 8.5 | Stable | При доступности устройства | Не используется | Ожидается от владельца |
| One UI 8.5 | Beta | При доступности устройства | Не используется | Ожидается от владельца |
| One UI 9.0 | Stable | После появления среды | Не используется | Среда/результат не подтверждены |
| One UI 9.0 | Beta | После появления среды | Не используется | Среда/результат не подтверждены |
| Android 16+ | Dev | Дополнительная | Не используется | Не проверено |
| Android 16+ | Canary | Экспериментальная | Не используется | Не проверено |

В отчёте фиксируются точная версия/пакет выбранного WebView, производитель/модель,
Android/API и One UI (по экрану устройства, не по догадке на основании API).
Проблемы конкретной Beta записываются с её точной версией. Статус «latest» требует
фактической проверки обновлений владельцем; имя пакета не подтверждает свежесть.

## Что CI измеряет сейчас

Эмуляторные API 36/37 проходят native-тесты. До/после прогона сохраняются
`android-environment/before.json` и `after.json`: manufacturer, model, Android/API,
выбранный provider package/version и предполагаемый канал по известному имени пакета.
`com.android.webview` обозначается AOSP, не Latest Stable. Неизвестный OEM остаётся unknown.
Отсутствие провайдера и неизвестный/нечитаемый ответ различаются. Наличие WebView не
требуется нативному приложению. Сырые dumpsys, serial, fingerprint, SIM, IP и конфигурация
не сохраняются. Collector адресует только CI-эмулятор и не ищет личные телефоны.

Эта инвентаризация не устанавливает/переключает WebView, не доказывает Latest Stable/Beta,
совместимость веб-страниц или обновление renderer. Эти результаты не отмечаются выполненными.
