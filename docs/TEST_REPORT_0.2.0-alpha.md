# Проверка 0.2.0-alpha

15 октября 2026 UTC. [English](en/TEST_REPORT_0.2.0-alpha.md).
Android 15+ / minSdk 35, versionName `0.2.0-alpha`, versionCode 5.
Основой остаётся проверенная 0.1.3; [политика 0.2](RELIABILITY_0.2.md).

## Локальные проверки

Полная Wrapper-команда с JDK 17: **BUILD SUCCESSFUL**.
На финальном исходном коде: **139 JVM-тестов**, 0
failures/errors/skipped; Android Lint **0 errors**, 3 прежних `UseKtx` warnings.
Debug APK и instrumentation APK собраны; в исходниках **14 обязательных
Android-тестов**, включая 5 циклов start → две сессии/пул → stop и проверку потоков.

Прежние Flowseal v1.11.2 golden vectors и unit-тесты сохранены. Новые сценарии:
одноразовые leases/CTR isolation, свежесть/лимиты/rotation, отменённые и поздние
сокеты, nonce-Pong и отказ при ранних данных, backoff/reset и отсутствие ложной
ошибки активной сессии при неудаче фонового warmup.

Расширенный локальный TCP/TLS/WSS soak — **180 с**:

Это локальный независимый peer с Java AES-CTR, ef/ee/dd, фрагментацией,
несколькими пакетами на сессию и намеренными WSS-отказами. Результаты проверены
по JUnit скриптом `verify_soak.py`; стенд не использует аккаунт Telegram.
Полная проверка с этим soak прошла для финальных исходников; CI повторит
60-секундный прогон для точного выпускаемого commit.

**11 Node.js тестов** реле, **22 теста CI-скриптов**, **4 publication guards** и
actionlint прошли. Новый CI gate отклоняет короткий/пустой/пропущенный soak,
ошибки, неполную статистику, отсутствие TCP/WSS/reset и превышение лимитов.

## GitHub CI

Сборка, фактический 60-секундный soak и по 14 Android-тестов на API 35/36/37.0
должны завершиться после push. Перед debug-публикацией результаты будут
скачаны и проверены по реальным JUnit; source, checksum и подпись фиксируются.

## Ограничения

Физический Telegram 0.2.0, продолжительные реальные Wi-Fi/LTE, внешний relay
и доступность у мобильного оператора **не проверены**. Пользовательские сведения
о Wi-Fi 0.1.0/0.1.1 не подтверждают новую версию. TCP и relay не прогреваются;
пулы активных MTProto-сессий не используются. Бесшовная миграция, Fake TLS,
полные Cloudflare-транспорты и HTTP/2 не добавлены. Это debug-предрелиз с
сохранённым debug-ключом, не production-подпись и не закрытый стабильный release gate.
