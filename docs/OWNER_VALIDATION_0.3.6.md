# Проверка владельцем — 0.3.6-alpha

Источник: ответы владельца на опрос в чате разработки, 19 октября 2026. Статус: **частично проверено владельцем; есть подтверждённые сбои**. Это физическая проверка пользователя, отдельная от CI и эмуляторов.

Среда: Samsung Galaxy A16, Android 16 / One UI 8.5, Telegram 13.0.3 (уточнено владельцем в чате). Оператор указан владельцем как «Мега5G»; ранее он уточнял Мегафон, Москва/Московская область. Режимы — прямой и только реле; тип/версия внешнего реле не уточнены. Секреты и адрес узла не собираются.

| Что проверялось | Результат владельца | Границы результата |
|---|---|---|
| Обновление и сохранение настроек | Пройдено | Секрет, порт и параметры реле сохранились |
| Подпись минимальной ОС | Пройдено | В About написано Android 16+ |
| Несколько циклов запуска/остановки | Сообщение об ошибке | Владелец уточнил «Ошибка Obfuscated2»; источник сообщения и остановка listener ещё не подтверждены |
| Текст Telegram | Пройдено | Отправка и получение |

Связь отказов в поездках с конкретными вышками — наблюдение/предположение владельца, а не подтверждённая техническая причина. Операторские ограничения, зависший маршрут и ошибка клиента пока не разделены. Результат не означает доступность всех узлов во всех сетях.

HTTP/2, Fake TLS, автоматический CF и отдельные WebView-каналы этим ответом не подтверждены. Встроенного WebView в TGWS нет: renderer/page API и Live Updates/Quick Settings без реализации не входят в список неудачных тестов приложения. One UI 8.5 подтверждён для перечисленных базовых сценариев, не для всех функций платформы.

## Следующие исправления

1. Воспроизвести сбой start/stop с уточнением источника Obfuscated2/состояния listener, добавить Android-регрессию и проверить освобождение listener/потоков.
2. Воспроизвести зависание восстановления сети и длительной сессии; отдельно проверить потерю default network и сбой соединения без смены Network.
3. Для HD/кружков проверить общий тракт клиента: отказ есть в direct и relay. Уточнить отправку/скачивание; сопоставить только безопасные категории Close и счётчики. Worker 16 МиБ не объясняет сам по себе отказ direct; причина в конкретной сессии не установлена.

Обновление 0.3.7 переносит этот версионированный отчёт в UI и документацию. Оно не объявляет перечисленные сбои исправленными или 0.3.7 проверенной на телефоне. [Машиночитаемый отчёт](owner-validation.json) · [CI 0.3.6](TEST_REPORT_0.3.6-alpha.md).
