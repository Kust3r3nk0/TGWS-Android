# Проверка владельцем — 0.3.6-alpha

Источник: ответы владельца на опрос в чате разработки, 19 октября 2026. Статус: **частично проверено владельцем; есть подтверждённые сбои**. Это физическая проверка пользователя, отдельная от CI и эмуляторов.

Среда: Samsung, Android 16 / One UI 8.5. Точный индекс модели и текущая версия Telegram уточняются. Оператор указан владельцем как «Мега5G»; ранее он уточнял Мегафон, Москва/Московская область. Режимы — прямой и только реле; тип/версия внешнего реле не уточнены. Секреты и адрес узла не собираются.

| Что проверялось | Результат владельца | Границы результата |
|---|---|---|
| Обновление и сохранение настроек | Пройдено | Секрет, порт и параметры реле сохранились |
| Подпись минимальной ОС | Пройдено | В About написано Android 16+ |
| Несколько циклов запуска/остановки | Ошибка | Конкретный симптом уточняется |
| Текст Telegram | Пройдено | Отправка и получение |
| Обычные фотографии | Работают | Направление передачи и распределение по режимам не уточнены |
| HD-фотографии | Ошибка | Направление/режим и причина не установлены |
| Голосовые сообщения | Работают | Направление передачи и распределение по режимам не уточнены |
| Видеокружки | Ошибка | Направление/режим и причина не установлены |
| Файл 1–5 МиБ | Не проверено | Владелец выбрал этот ответ |
| Wi-Fi и мобильный интернет | Частично пройдено | Обе сети работают; в поездках бывают участки без рабочего соединения |
| Смена Wi-Fi ↔ мобильная сеть | Ошибка | Соединение восстанавливается только после перезапуска прокси |
| Длительная работа | Ошибка стабильности | Иногда краткое восстановление, иногда требуется ручной перезапуск; точная длительность не указана |
| Темы, Liquid Glass, прозрачность | Пройдено | Работают и сохраняются после закрытия приложения |

Связь отказов в поездках с конкретными вышками — наблюдение/предположение владельца, а не подтверждённая техническая причина. Операторские ограничения, зависший маршрут и ошибка клиента пока не разделены. Результат не означает доступность всех узлов во всех сетях.

HTTP/2, Fake TLS, автоматический CF и отдельные WebView-каналы этим ответом не подтверждены. Встроенного WebView в TGWS нет: renderer/page API и Live Updates/Quick Settings без реализации не входят в список неудачных тестов приложения. One UI 8.5 подтверждён для перечисленных базовых сценариев, не для всех функций платформы.

## Следующие исправления

1. Воспроизвести сбой start/stop по уточнённым шагам, добавить Android-регрессию и проверить освобождение listener/потоков.
2. Воспроизвести зависание восстановления сети и длительной сессии; отдельно проверить потерю default network и сбой соединения без смены Network.
3. Для HD/кружков разделить direct/relay и направления; сопоставить только безопасные категории Close и счётчики. Worker 16 МиБ остаётся гипотезой для конкретного отказа, не установленной причиной.
