# Критерии стабильного выпуска

Обновление 0.3.5-alpha устраняет подтверждённые дефекты исходников. Оно не является production-релизом.

| Проверка | Состояние |
|---|---|
| Эталонные MTProto/Fake TLS векторы Flowseal v1.11.2 | Сохранены, повторная побайтовая сверка успешна |
| JVM/Lint/Debug APK | Локально 195 тестов, 0 ошибок Lint; окончательные CI результаты в отчёте версии |
| Установка APK поверх 0.3.4 с сохранением Keystore | Добавлена отдельная обязательная CI-регрессия на API 35/36/37 |
| Telegram: сообщения/медиа, перезапуск и 30–60 минут с выключенным экраном | Владелец по TGWS-16-017; новая версия ожидает проверки |
| Мобильная сеть и проблемные Wi-Fi | Доступность внешнего узла ещё не подтверждена; DNS не устраняет блокировку IP/SNI |
| WebView Stable/Beta и One UI | TGWS-16-016: встроенного WebView нет; реальные каналы/OEM проверяет владелец |
| Подпись и распространение стабильного APK | Требуется доверенная production-подпись и определённый путь перехода с debug-подписи |

## Ошибка на скриншоте 0.3.4

Владелец сообщил о 2529 отклонённых заголовках и предположил изменение секрета при обновлении; явной генерации или импорта не подтверждал.
Проверка `SECRET_OR_TRANSPORT` выполняется до удалённого подключения. Она не устанавливает причину блокировки оператором и не доказывает автоматическую замену ключа при установке APK.

Найдены независимые воспроизводимые дефекты: обрезание вставленного prefixed secret, экспорт несохранённого секрета и генерация нового при частичной потере записи. Для всех добавлены проверки.
При обычном обновлении с той же подписью существующие данные должны сохраняться. Удаление приложения/очистка данных создают новую установку; ошибка подписи не требует удаления — используйте обновление с прежним сертификатом.

После установки откройте текущую ссылку из приложения. Если Telegram хранит старую запись с тем же адресом, отключите её и добавьте текущую ссылку. Секрет в отчёты не включать.
