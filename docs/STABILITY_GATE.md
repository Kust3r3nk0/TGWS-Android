# Критерии стабильного выпуска

[Владелец проверил 0.3.6](OWNER_VALIDATION_0.3.6.md) на Android 16 / One UI 8.5. Статус — **частично проверено, есть сбои**. Успех CI не отменяет эти результаты.

| Проверка | Фактическое состояние |
|---|---|
| Текст Telegram, обычные фото, голосовые | Владелец подтвердил; направления медиа уточняются |
| Секрет/порт/реле после обновления, темы/эффекты | Владелец подтвердил сохранность |
| Повторные start/stop | Сообщение «Ошибка Obfuscated2»; источник и состояние listener уточняются |
| HD-фото и видеокружки | Ошибка в direct и relay; направление уточняется |
| Wi-Fi и мобильный интернет | Работают с отказами в отдельных поездках |
| Автоматическое восстановление сети | Не пройдено: требуется ручной перезапуск |
| Длительная устойчивость | Не пройдено: иногда нужен ручной перезапуск |
| Файл 1–5 МиБ | Не проверено |
| One UI 8.5 | Базовые сценарии выше подтверждены; все OEM-функции не заявляются |
| Встроенный WebView | Не используется; renderer/page тесты неприменимы |
| Автоматические проверки | [0.3.6](TEST_REPORT_0.3.6-alpha.md), [0.3.7](TEST_REPORT_0.3.7-alpha.md), отдельно от телефона |
| Production-подпись | Требуется доверенный ключ и путь перехода с debug |

До стабильного релиза нужны исправления зарегистрированных сбоев, повторная проверка соответствующих сценариев владельцем и production-подпись. 0.3.7 обновляет отчёт, а не объявляет исправление HD или восстановления сети.

Worker сохраняет лимит 16 МиБ/сессию; его срабатывание в конкретном случае не подтверждено. Отказы в поездках не доказывают блокировку конкретных вышек. Проверки TLS и секретов не ослабляются.
