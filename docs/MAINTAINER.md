# Памятка сопровождающему

Репозиторий публичный. Android CI успешно выполняет JVM-тесты, Lint и сборку debug APK. Следующий обязательный шаг — проверка соединений на реальном Android 15+.

Рекомендуемые темы GitHub: `android`, `kotlin`, `jetpack-compose`, `telegram`, `mtproto`, `websocket`, `open-source`.

Рекомендуемые настройки: Issues, Dependabot alerts, Private vulnerability reporting. После успешного CI добавьте правила защиты ветки `main`.

Владелец разрешил debug GitHub Pre-releases 15 октября 2026. Публикуйте после обязательного CI и проверок API 35–37, явно указывайте отладочную подпись, APK/SHA256/build metadata/результаты тестов. Стабильный релиз требует полного release gate ТЗ. Доступ интеграции к Actions secrets возвращает HTTP 403: постоянная CI-подпись требует настройки владельцем; ключи не коммитить.

[English version](en/MAINTAINER.md)

Debug-релизы подписываются сохранённым ключом рабочей среды вне Git (закрытый каталог `/workspace/private-signing/`). Перед повторной публикацией сверяйте сертификат с предыдущим debug-релизом. Если ключ недоступен, не обещайте установку поверх прежней версии. Ключи и их резервные копии не добавлять в GitHub Releases.
