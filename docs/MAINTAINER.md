# Памятка сопровождающему

Репозиторий публичный. Сначала требуется успешное выполнение Android CI, затем проверка приложения на реальном Android 14+.

Рекомендуемые темы GitHub: `android`, `kotlin`, `jetpack-compose`, `telegram`, `mtproto`, `websocket`, `open-source`.

Рекомендуемые настройки: Issues, Dependabot alerts, Private vulnerability reporting. После успешного CI добавьте правила защиты ветки `main`.

Не создавайте GitHub Releases и не объявляйте приложение стабильным, пока нет подтверждённых результатов сборки, интеграционных тестов и проверки подключений.
