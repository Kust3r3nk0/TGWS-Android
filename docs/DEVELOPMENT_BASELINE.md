# ТЗ и действующие уточнения

Источник: техническое задание владельца от 14 октября 2026 в чате разработки.
План следующих этапов — [ROADMAP.md](../ROADMAP.md), правила — [AGENTS.md](../AGENTS.md).
Последующие явные указания владельца имеют приоритет над исходными параметрами.

## Постоянные требования исходного ТЗ

- Нативный Android/Kotlin/Compose/Material 3, MIT, сохранение package/applicationId,
  истории и существующих тестов. Не VPN, без VpnService и Python в APK.
- Эталон протокола: Flowseal/tg-ws-proxy v1.11.2, commit
  `307a384ab7f522e34bb1a045884d0bd90f40bee5`. Побайтовые тестовые векторы,
  независимые AES-CTR состояния, SHA-256/SecureRandom, Obfuscated2 ef/ee/dd.
- Loopback-only listener, bounded framing, строгий RFC 6455, проверка TLS и имени,
  ограниченный WSS → TCP fallback, владение/освобождение сокетов, конечные сроки.
- Foreground Service после действия пользователя; состояние listener отдельно
  от удалённых сессий. Keystore AES-256-GCM, секрет скрыт, восстановление явно.
- Без секретов, ключей, пакетов или пользовательских сообщений в диагностике.
  RU/EN ресурсы. Не выдавать компиляцию или показание ping за полный E2E.
- Полная команда Wrapper: `./gradlew --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`.
  Не отключать проверки. Заявлять только фактически проверенные возможности.
- Исходная граница 0.1 исключала Fake TLS/CF/H2; актуальный этап 0.3 расширен новым
  [ТЗ владельца](TZ_0.3.0-alpha.md). Протокольная корректность и прежние тесты сохраняют приоритет.

## Действующие уточнения владельца (обновлено 19 октября 2026)

- Текущая разработка — **только Android 16+ / minSdk 36**. Устаревшие платформенные ресурсы и отчёты удалены из текущего дерева; изменения остаются в истории Git.
- Использовать предоставленный логотип. Установленное название — **TGWS-Android**
  без Alpha; стадия alpha сохраняется в версии до прохождения соответствующих gates.
- Обновлять файлы GitHub, changelog и roadmap; публикация debug-предрелизов
  разрешена. Debug APK не является стабильным production-релизом.
- После CI и реальной матрицы API 36/37 публиковать debug APK, checksum,
  commit, build metadata, результаты тестов и известные ограничения в Pre-release.
- Стабильный релиз по-прежнему требует подтверждённого полного Telegram E2E,
  отсутствия критических дефектов и доверенной подписи. Не объявлять 1.0 по компиляции.

## Текущее задание 0.3.0-alpha

[Полное ТЗ](TZ_0.3.0-alpha.md) объединяет прежние 0.3/0.4: Fake TLS, CF Proxy/Worker,
совместимый H2 media, диагностика и активный Android Network, четыре операторские карточки.
Физические Telegram/Wi-Fi/cellular/длительные screen-off проверки выполняет лично владелец.
Не запрашивать ADB/устройство и не задерживать debug-предрелиз ожиданием этих результатов.
После автоматических проверок публикуется debug APK с версией и checksum. Личные отчёты и сведения об устройствах/операторах не публикуются. Стабильный релиз остаётся отдельным gate.


## Уточнение интерфейса и DNS (16 октября 2026)

Владелец запросил две нижние вкладки, отдельные настройки, переключение светлой/тёмной
темы, единый Material 3 и автоматическое отображение Wi-Fi/мобильной сети и IP-семейств.
Общедоступный Cloudflare DNS разрешён как явно выбираемый app-scoped DoH; системные
APN/DNS/SIM по-прежнему не изменяются. При обновлении прежний системный resolver и
защищённая конфигурация прокси сохраняются. Проверку на физическом телефоне выполняет владелец.


## Дополнения TGWS-16-016 / TGWS-16-017 (16 октября 2026)

Обязательны [WebView-контракт](TGWS-16-016_WEBVIEW.md) и [порядок физических проверок](TGWS-16-017_PHYSICAL_TESTING.md).
Встроенного WebView в 0.3.3 нет: WebKit, renderer recovery и browser API сейчас неприменимы;
скрытый движок/MTProto через JS запрещены. В CI добавлены контроль production-деклараций
и безопасные сведения о провайдере среды, без утверждения «latest Stable/Beta проверен».
Матрица Android 16+/One UI выполняется владельцем на доступных смартфонах; общий minSdk 36; поддерживаются только API 36 и новее.
Codex отвечает за код, автоматические проверки и передачу APK с версией/SHA/ссылкой/ограничениями;
владелец — за все физические результаты. Телефон/ADB не запрашиваются, debug не задерживается
ожиданием ручной проверки, стабильный release gate остаётся отдельным.

## Сети: уточнение 16 октября 2026

Удалить встроенный Cloudflare DNS; использовать активный Android Network. Сохранить прочие настройки и настроенные реле. Реальные отказы операторов/некоторых Wi-Fi требуют физического повторного теста владельцем; отделять исправление клиента от блокировки IP/домена и ограничений внешнего узла. [Исследование](NETWORK_COMPATIBILITY_0.3.4.md).
