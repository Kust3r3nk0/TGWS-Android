# TGWS WSS relay

В 0.5.0 собственное реле можно разрешить в Smart-профиле автоматического режима;
«Только реле» по-прежнему не открывает прямые соединения. Токен/URL сохраняются
в существующем зашифрованном хранилище. Multi-VPS Manager относится к 0.6.0.
[Профили и проверка](../docs/SMART_CONNECTION_0.5.0.md).

Сервер для собственного внешнего хоста; не входит в APK.
[Настройка и ограничения](../docs/MOBILE_NETWORKS.md) ·
[English](../docs/en/MOBILE_NETWORKS.md).

Проверка: `npm ci --ignore-scripts && npm test` (Node.js 22+).
Используется публичная тестовая TLS-идентичность localhost из JVM fixtures;
она не подходит для развёртывания. Production TLS key и токен хранятся вне Git.

Для крупных передач это альтернатива ограниченному Worker: Node.js использует
stream backpressure в обоих направлениях. В 0.4.2 не меняются протокол реле,
allowlist DC/портов и зашифрованный URL приложения. Переход выполняется явно для
новых сессий после остановки/сохранения настроек; replay активной сессии отсутствует.
[Сценарий приёмки и план нескольких VPS-реле](../docs/SMART_CONNECTION_UPDATE.md).

0.6.0: [установка, systemd, ограничения и обновление](../docs/VPS_RELAY.md). Node-реле 0.2.0 сохраняет wire protocol; для bounded-write и close fixes обновите серверный код.
