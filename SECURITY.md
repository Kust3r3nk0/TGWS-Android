# Политика безопасности

**Статус:** TGWS-Android 0.6.1 является тестовым обновлением кандидата; полноценный аудит безопасности не проводился. Не используйте раннюю версию в качестве единственного канала связи.

## Сообщение об уязвимости

Не публикуйте реальные секреты MTProto, ключи, персональные данные и потенциально эксплуатируемые уязвимости в открытых Issues. Если в репозитории включена функция GitHub **Security → Report a vulnerability**, воспользуйтесь ею. В противном случае сначала свяжитесь с сопровождающим приватно через профиль GitHub и согласуйте защищённый канал.

## Принципы

- Локальный сервер по умолчанию слушает только `127.0.0.1`.
- Секреты не должны попадать в журнал, баг-репорт или открытые настройки.
- Сертификаты TLS и имена хостов должны проверяться; исключения требуют описания и тестов.
- Для всех сетевых операций необходимы лимиты памяти, тайм-ауты и корректное освобождение ресурсов.
- Обновления зависимостей проходят проверку CI.
