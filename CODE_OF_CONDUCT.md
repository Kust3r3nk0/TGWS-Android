# Кодекс поведения сообщества

Мы приветствуем конструктивное техническое обсуждение. Участники проекта обязуются общаться уважительно, предоставлять воспроизводимые сведения об ошибках, избегать оскорблений, преследования и публикации чужих персональных данных.

Не размещайте чужие токены, пароли, ключи и журналы, содержащие конфиденциальную информацию. Сопровождающий проекта может удалять нарушающие эти правила материалы и ограничивать участие.

Для конфиденциальных обращений свяжитесь с сопровождающим через профиль GitHub.
