# Как помочь проекту TGWS-Android

Спасибо за помощь проекту. Pull Requests и баг-репорты приветствуются.

## Перед Pull Request

1. Создайте Issue для крупных функциональных изменений и согласуйте границы реализации.
2. Сохраняйте совместимость с Android 14+ (API 34) и используйте только стабильные версии зависимостей.
3. Отдельно документируйте изменения поведения протоколов относительно Flowseal/tg-ws-proxy.
4. Не коммитьте ключи, пароли, реальные идентификаторы пользователей, диагностические логи с секретами, APK-подписи и частные сетевые данные.
5. Обязательно пишите тесты, особенно для фрейминга, шифрования и восстановления соединений.
6. Обновляйте `ROADMAP.md` и документацию, если меняется функциональность.

## Проверки

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

В репозитории доступен полный Gradle Wrapper 9.8.1. В Windows используйте `gradlew.bat`.

## Стиль PR

Один PR — одна небольшая функциональная цель. В описании укажите:
- что изменено и почему;
- какая часть исходного кода Flowseal затронута;
- как проверяли и какие результаты;
- известные ограничения Android и протокольные отличия.
