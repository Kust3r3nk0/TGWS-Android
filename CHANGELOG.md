## 0.3.9-alpha — сетевые исправления

- При включённом Fake TLS сохранён приём обычного Obfuscated2 с тем же секретом, как в Flowseal. Случайный заголовок, похожий на TLS, сначала проверяется как Obfuscated2; отказ Fake TLS имеет отдельную категорию.
- Крупный MTProto-пакет передаётся одним WebSocket-сообщением с фрагментами до 64 КиБ. Продвижение записи обновляет сроки; действительно зависшая запись по-прежнему закрывается. Ping/Pong может передаваться между фрагментами.
- При скачивании срок частичного сообщения продлевается только после 64 КиБ данных, с общим пределом в пять окон чтения. Контрольные кадры и медленная побайтовая передача срок не продлевают.
- Приостановка/возобновление и блокировка/разблокировка той же Android-сети очищают старые соединения, DNS, пул и backoff. TCP_USER_TIMEOUT ограничивает неподтверждённые данные 30 секундами; listener сохраняется для нового подключения Telegram.
- VersionCode 15, Android 16+, прежние applicationId/сертификат/защищённые настройки. Личные отчёты не публикуются. Лимит прежнего Worker 16 МиБ/сессию остаётся; все внешние сетевые ограничения этим обновлением не устраняются.

## 0.3.5-alpha — сохранение секрета и устойчивость сессий

- Исправлена вставка `dd`/`ee` secret: ключ больше не обрезается до ошибочных 32 символов, домен Fake TLS распознаётся.
- Копирование/открытие Telegram-ссылки и копирование секрета сохраняют конфигурацию до передачи; ошибка Keystore блокирует экспорт.
- Отсутствие секретной записи при сохранённых настройках/ключе больше не считается первым запуском; требуется явное восстановление.
- Пустая локальная TCP-проверка не создаёт ошибку сессии; неполный handshake и тайм-аут имеют отдельные категории, включая Fake TLS.
- Устранена гонка копирования concurrent-коллекций при остановке и отмене сетевых подключений; добавлены детерминированная и конкурентная регрессии.
- Остановка очищает текущую ошибку сессии, поздние callbacks не возвращают работающий статус. Счётчик отказов отмечен как история последнего запуска.
- Добавлены регрессии UI, Keystore, lifecycle и установка обновления поверх APK 0.3.4 в CI.
- Диагностика медиа из PR #16: трафик по маршрутам/DC и безопасные категории WSS Close; тесты Worker с большими бинарными передачами. Production-лимит Worker 16 МиБ сохранён; HD E2E не подтверждён.
- Подготовка к стабильному выпуску: физическая проверка владельца, доступность мобильных маршрутов и production-подпись ещё необходимы.

## 0.3.4-alpha — 2026-10-16

- Удалены встроенный Cloudflare DNS, переключатель и DoH runtime-зависимость. Старый выбор мигрирует на системный DNS без изменения остальных настроек.
- Ограниченный Happy Eyeballs для TCP: IPv4/IPv6, шаг 250 мс, две попытки на соединение, общий deadline и закрытие проигравших сокетов.
- При отмене DNS-запроса Android немедленно освобождается ожидающий worker; при потере сети отменяются запросы.
- Сохранены прежние DoH-тесты как test-only fixtures; добавлены сетевые регрессии, миграция и APK DEX guard.
- Сохранены настроенные Worker/CF/H2 и строгая проверка TLS. Добавлен разбор DNS/IP/SNI/captive portal/IPv6/allowlist с первичными источниками.
- Включён процесс TGWS-16-016/017: нативный UI без WebView, CI-инвентаризация провайдера и handoff для физических проверок владельцем.
- Мобильный интернет/реальный Wi-Fi/Telegram этой сборкой ещё не подтверждены; универсальный обход блокировок не заявляется.

## [0.3.0-alpha] — 2026-10-16 (debug)

- Этапы 0.3/0.4 объединены: Fake TLS HMAC/records и ee-ссылки, конфигурация CF Proxy/Worker, совместимый HTTP/2 media `/api`.
- Режимы direct, relay-only и Auto CF; Worker → CF → TCP, ограниченная ротация/backoff, без replay. Relay-only не открывает прямой путь.
- HTTP/2: строгий TLS/ALPN, два запроса на native-сессию, ограничение очередей/ответов, flow control, RST/GOAWAY/cancel. Добавлен стабильный OkHttp 5.5.0; остальной стек сохранён.
- Привязка DNS/сокетов к Android Network, IPv4/IPv6/DNS64 средствами ОС; отмена при смене сети. Callback lifecycle без дополнительных wake locks.
- Диагностика этапов/маршрутов/сети/трафика, фактические DNS/TCP/TLS/HTTP замеры, ручной probe и обезличенный экспорт с предпросмотром. Исправлены замеры TLS при конкурентном выборе адресов.
- Справочник четырёх российских операторов без изменения APN/DNS/SIM; data-SIM и PLMN регистрации не смешиваются. Новые параметры защищены Keystore; настройки 0.2 мигрируют без смены режима.
- Сохранены прежние тесты; добавлены векторы upstream, локальные TLS/H2/Fake TLS и Android migration/cleanup тесты; обязательные TCP/WSS и H2 soak в CI.
- versionCode 6, прежние applicationId/логотип/debug-сертификат. Проверка владельцем на физическом устройстве: ожидается. Мобильные операторы и внешние CF/Worker E2E не проверены; гарантия обхода не заявляется.

## [Unreleased] — Cloudflare Worker, отдельно от APK

- Локальные тесты, bundling стабильным Wrangler и CI-артефакт готового модуля. Новый APK не требуется; Android-код/версия/подпись не менялись.
- Инструкция RU/EN: реальный Worker SNI вместо подстановки чужого `cloudflare.com`. Развёртывание в аккаунте владельца и доступность внешнего узла зависят от сети. Шаблон может прерывать большие загрузки и не обозначается как исправление стабильности.

## [0.2.0-alpha] — 2026-10-15 (debug)

- Одноразовый пул ещё не использованных прямых WSS-подключений: четыре в сумме, один сокет на маршрут, два фоновых connect-потока, 30 с свежести. Перед init проверяется совпадающий Pong; активные MTProto-сессии не переиспользуются.
- Ротация и очистка по смене сети/stop; отменённые и запоздавшие сокеты закрываются. Нет бесконечного фонового refill без спроса. Relay и TCP не прогреваются.
- Per-route backoff setup-отказов 1–30 с, одна проверочная попытка после паузы, защита от запоздалых результатов и сброс при смене сети. Без replay MTProto payload.
- Тесты пула, Ping/Pong и backoff; стенд с реальными локальными TCP/TLS/WSS, ef/ee/dd, длительными CTR-потоками, конкурентными клиентами и сетевыми сбросами. CI включает 60-секундный soak.
- Эталон Flowseal v1.11.2 и стабильные зависимости сохранены; versionCode 5.
- Реальные Telegram 0.2.0, Wi-Fi/LTE и внешний relay E2E требуют проверки. Стабильный release gate не пройден.

## [0.1.1-alpha] — 2026-10-15 (тестовая сборка)

### Исправлено
- Живые WSS-сессии больше не закрываются через один общий 60-секундный срок ожидания: Ping/Pong обновляют ожидание, при тишине отправляется Ping с ограниченным сроком ответа.
- Срок сборки фрагментированного сообщения и ограничения памяти сохраняются; зависший peer закрывается, неверный Pong не подтверждает heartbeat.
- Заголовок, маска и данные WebSocket буферизуются перед TLS-записью; включён TCP_NODELAY.
- Предел бездействия MTProto-сессии увеличен с 60 до 300 секунд; сроки handshake/connect/write не изменены.
- После успешного нового соединения снимается устаревшая ошибка fallback. При работающих сессиях ошибка другой сессии показывается как последнее событие; отдельные счётчики WSS/TCP показывают фактический транспорт.
- versionCode увеличен до 2; имя CI-артефакта берётся из versionName.

### Проверки и ограничения
- Обновление 0.1.1-alpha требует повторной проверки на том же устройстве; причины всех реальных разрывов пока не установлены. Подробности: [Проверки для разработчиков](docs/TESTING.md).

- CI закреплён по SHA, публикует checksum, build metadata и отчёты; добавлены инструментальные тесты и отдельная матрица Android.
- CI отклоняет пустые и неполные Android-отчёты, проверяет фактический API эмулятора; исправлены запуск зависимых shell-команд и метаданные AVD API 37.0, добавлены 16 тестов CI-скриптов.
- Версия остаётся `0.1.0-alpha`; физический Telegram E2E не выполнен, tag и Pre-release не создаются до прохождения release gate.
