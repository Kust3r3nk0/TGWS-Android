# План развития TGWS-Android

Статусы ниже обозначают **состояние исходников**, а не подтверждённую работу на реальном устройстве.

## 0.1.0-alpha — исходная Android-версия
- [x] Исходники UI на Kotlin и Jetpack Compose
- [x] Первичная реализация MTProto obfuscated2 / AES-CTR
- [x] Первичная реализация WSS и TCP fallback
- [x] Android Foreground Service и хранение настроек через Keystore
- [x] Исходники модульных тестов
- [ ] Успешная Android CI-сборка
- [ ] Реальные end-to-end тесты Telegram

## 0.2.0 — надёжность и совместимость
- [ ] Эталонные тест-векторы относительно оригинала Flowseal
- [ ] Строгая проверка WebSocket Upgrade и MTProto handshake
- [ ] Пулы соединений, ротация и контролируемые повторные попытки
- [ ] Проверки тайм-аутов, отмены задач, ограничений памяти и журналов

## 0.3.0 — расширенные транспорты
- [ ] Fake TLS и маскировка
- [ ] Cloudflare Proxy и Worker fallback
- [ ] HTTP/2 и медиатрафик
- [ ] Диагностика состояния маршрутов

## 0.4.0 — оптимизация Android
- [ ] IPv4, IPv6 и IPv6-only при поддержке сетевой среды
- [ ] Восстановление при переключении Wi-Fi и мобильной сети
- [ ] Энергосбережение и контроль работы в фоне
- [ ] Инструментальные тесты на устройствах

## 1.0.0 — стабильный выпуск
- [ ] Проверка соответствия функциональности Flowseal
- [ ] Подписанная сборка и релизная документация
- [ ] Успешные тесты и отчёт об известных ограничениях
