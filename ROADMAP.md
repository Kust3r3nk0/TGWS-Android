## 0.3.5-alpha — сохранение секрета и устойчивость сессий

- Исправлена вставка `dd`/`ee` secret: ключ больше не обрезается до ошибочных 32 символов, домен Fake TLS распознаётся.
- Копирование/открытие Telegram-ссылки и копирование секрета сохраняют конфигурацию до передачи; ошибка Keystore блокирует экспорт.
- Отсутствие секретной записи при сохранённых настройках/ключе больше не считается первым запуском; требуется явное восстановление.
- Пустая локальная TCP-проверка не создаёт ошибку сессии; неполный handshake и тайм-аут имеют отдельные категории, включая Fake TLS.
- Остановка очищает текущую ошибку сессии, поздние callbacks не возвращают работающий статус. Счётчик отказов отмечен как история последнего запуска.
- Добавлены регрессии UI, Keystore, lifecycle и установка обновления поверх APK 0.3.4 в CI.
- Диагностика медиа PR #16, безопасные WSS Close и корректный CLOSED после закрытия последнего клиента; Worker 16 МиБ сохранён.
- Устранена гонка снимков concurrent-коллекций при остановке и смене сети.
- [x] [Проверки для разработчиков](docs/TESTING.md): 203 JVM, Lint без ошибок, 17 Worker; по 33 Android-case и успешное обновление поверх 0.3.4 на API 36/37.
- Подготовка к стабильному выпуску: физическая проверка владельца, доступность мобильных маршрутов и production-подпись ещё необходимы.

## 0.3.0-alpha — расширенные транспорты и Android

Этап объединяет прежние 0.3.0 и **все пункты прежнего сетевого этапа 0.4.0** (не редизайн Premium Minimal). [Актуальное ТЗ](docs/TZ_0.3.0-alpha.md).
Отметки означают реализацию и автоматические проверки; физическая приёмка отмечена отдельно.

- [x] Fake TLS: HMAC ClientHello/ServerHello, `ee`-ссылки, record framing, побайтовые векторы v1.11.2
- [x] Отдельные direct / relay-only / автоматический CF; Worker → CF Proxy → TCP, ограниченная ротация/backoff без replay
- [x] Конфигурируемые проверяемые домены `kwsN.<base>` и Worker endpoints; зашифрованная конфигурация, миграция 0.2
- [x] HTTP/2 для совместимого CF media `/api`: ALPN, multiplexing, flow control/backpressure, RST/GOAWAY и отмена
- [x] Диагностика маршрутов, этапов, активной сети, сессий, трафика и фактических замеров; ручной probe и обезличенный экспорт
- [x] IPv4/dual-stack, AAAA/DNS64/XLAT средствами активного Android Network; ограниченный fallback семейств
- [x] Wi-Fi ↔ мобильная сеть: отмена старых DNS/HTTP/socket, очистка пула/backoff и создание новых сессий
- [x] Энергосбережение: callbacks вместо polling, без фонового прогрева без спроса и дополнительных wake locks
- [x] Справочник МегаФон/МТС/билайн/T2, разделение data-SIM и PLMN регистрации, неизвестные/недоступные данные
- [x] Сохранены отдельные Worker-шаблон и собственное WSS-реле; серверные тесты
- [ ] Внешний CF/Worker → Telegram E2E, физические IPv6-only/переключения/30–60 минут с выключенным экраном
- [ ] Физическая матрица RU-01–14 по доступным SIM; проверку проводит владелец, без блокировки debug-предрелиза
- [ ] Полноценный flow control экспериментального Worker вместо его текущего лимита 16 MiB/сессию

[Режимы и ограничения](docs/TRANSPORTS_0.3.md) · [Операторы и матрица](docs/RU_MOBILE_OPERATORS.md) · [Проверки для разработчиков](docs/TESTING.md).
