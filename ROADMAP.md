# План развития TGWS-Android

Текущая минимальная ОС: **Android 15 / API 35** (указание владельца 15 октября 2026). Исторические этапы и отчёты сохраняются. Основа разработки — [ТЗ и уточнения](docs/DEVELOPMENT_BASELINE.md).

## 0.2.0-alpha — надёжность и совместимость
- [x] Сохранены побайтовые векторы Flowseal v1.11.2 и строгие WebSocket/MTProto handshake-проверки
- [x] Ограниченный пул свежих прямых WSS-подключений, одноразовые leases, Ping/Pong перед init
- [x] Ротация по возрасту без бесконечной фоновой дозаправки; отмена/закрытие при смене сети и stop
- [x] Контролируемый per-route backoff 1–30 с, одна пробная попытка, без replay пакетов
- [x] Локальные длительные TCP/TLS/WSS испытания с ef/ee/dd и сбросами сети
- [ ] Продолжительные реальные Wi-Fi/LTE испытания и Telegram E2E 0.2.0 на физическом устройстве
- [ ] Расширение эталонных векторов при отдельном обновлении upstream; в этой версии upstream не обновлён
- [Политика и ограничения](docs/RELIABILITY_0.2.md) · [Фактические проверки](docs/TEST_REPORT_0.2.0-alpha.md)

## 0.1.3-alpha — маршрут для сетей с блокировкой IP
- [x] Настраиваемое WSS-реле по контракту Flowseal Worker, отдельный режим без прямого fallback
- [x] Зашифрованное хранение URL, строгий TLS, счётчик relay-сессий, bounded DNS
- [x] Сервер собственного WSS-реле с ограниченными DC, ключом пути и stream backpressure; локальные TLS/TCP тесты
- [ ] Развёртывание доступного внешнего узла и Telegram E2E в мобильной сети владельца
- Включено раньше расширенного этапа по запросу владельца о блокировке IP; это не полный Cloudflare-транспорт и не гарантия обхода.
- [Настройка и ограничения](docs/MOBILE_NETWORKS.md)

## 0.1.2-alpha — оформление и диагностика

Статусы ниже обозначают **состояние исходников**, а не подтверждённую работу на реальном устройстве.
